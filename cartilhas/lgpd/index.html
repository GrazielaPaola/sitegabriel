O QUE É A LGPD?

02/07

A LGPD (Lei Geral de Proteção de Dados) é uma lei brasileira que protege os dados pessoais dos cidadãos. Ela exige que empresas informem como usam seus dados e dá mais controle para os usuários sobre suas informações.

Propósito da LGPD

  • Proteção de dados pessoais
  • Transparência no uso de dados
  • Controle do usuário sobre suas informações
  • Regulamentação para empresas

O QUE É SEGURANÇA DA INFORMAÇÃO?

05/07

É o conjunto de práticas e tecnologias que protegem informações contra acessos não autorizados, vazamentos, fraudes e perdas.

Segurança não é só sobre senhas, mas sobre hábitos e sistemas seguros.
